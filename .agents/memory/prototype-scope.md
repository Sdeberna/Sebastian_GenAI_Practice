---
name: Prototype scope
description: User-defined boundaries for the inline email assistant class assignment.
---

The user wants a small, one-main-screen class prototype demonstrating an inline assistant in an email-writing experience, with prepared responses clearly labeled simulated. Keep the design simple and understandable, rather than feature-heavy.

**Why:** The user explicitly scoped the first prototype to demonstrate the interaction, not a production email or AI service.

**How to apply:** Do not add accounts, payments, dashboards, databases, real Gmail integration, external APIs, or computer-wide behavior without a new user request. “Cualquier espacio de texto” describes the motivating concept, not authorization to implement system-wide access.
